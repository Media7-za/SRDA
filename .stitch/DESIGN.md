# Phuket Thai Design System

This document defines the visual identity for the Phuket Thai mobile application layout.

**Brand Identity:**
Phuket Thai brings authentic, vibrant Thai street food and classic dishes to the modern user. The design should reflect energy, freshness, and frictionless ordering.

## 6. Design System Notes for Stitch Generation
Copy this block into every Stitch generation prompt to maintain consistency:

**DESIGN SYSTEM (REQUIRED):**
- **Platform:** Mobile-first web app (PWA), 390x844 resolution
- **Theme:** Clean, modern, bright with warm energetic accents
- **Background:** Off-White (#F8F9FA) for main body, Solid White (#FFFFFF) for cards and modals 
- **Primary Accent / Brand Color:** Thai Gold (#E6B325) for high-intent actions, active states, and bottom nav highlights
- **Secondary Accent:** Chili Red (#D9381E) for badges, alerts, and destructive actions
- **Text Primary:** Charcoal Noir (#1A1A1A) for headings and main reading text
- **Text Secondary:** Slate Gray (#64748B) for descriptions, disabled states, and subtitles
- **Typography:** Modern Sans-Serif (Inter or Roboto), bold readable headings for menu categories
- **Corners:** Gently rounded (12px to 16px) for cards and buttons
- **Elevation:** Subtle soft shadows for category tabs, floating cart, and bottom navigation
- **Interaction Rules:** High-intent buttons ("Add to Cart", "Checkout") should be full-width and highly visible.
